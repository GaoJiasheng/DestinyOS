## DESIGN-GAP

1. AstroChart 无上升星座字段，采用所有已支持宫位制均对应 ASC 的 houses[index=1].sign。
2. 六格局解释为五种已检测相位结构加 stats.stelliums，不虚构 features 字段。
3. 十四偏向解释为四元素/三模式各高低态；高计数 ≥4/5、低计数 ≤1，不声称唯一优势。
4. 半球集中 ≥6/10、象限集中 ≥5/10；无数字索引语法，象限用通配符判断并提示比较四组。
5. 相位章短文 80–120 字与 KU 200–450 字约束冲突；采用强制 schema 范围并提供短摘要。
6. schema 无 transits/features，当前行运章不作任何具体日期的行星位置声明。
7. 连续 [a=…][b=…][type=…] 筛选同一记录，补齐原解析器已接受但未执行的语法。
8. 覆盖率固定种子，1900–2100、20% 未知时辰、多个时区/半球、高纬与三宫位制。
