## DESIGN-GAP 列表
- 相似度使用去标点、空白后的字符 3-gram Dice 系数（中英一致）。
- 附录省略的范围采用常见 snake_case key；奇门天辅用 qimen.star.tian_fu 避免与紫微天府冲突。
- 初始术语 long 复用 short，待 T-23 内容扩写。
- 英文禁用词补充中文恐吓/承诺词的对应表达。
- 每章正文上限 6 KU，概览 3；daily key 按其领域/补充内容配置。
- 非八字体系保留权重和置信度钩子；基础评分公式未定义时取中性 3，可覆盖。
- 无出生时辰时置信度上限 0.65；engineVersion 缺省 0.0.0，可由调用方传入。
- 过渡池耗尽时使用段落间隔；依据 anchor 使用 URI 编码的 chart 路径。
- 占卜章节表没有总结章，按 05 §4 追加 summary_actions。
- 单字汉字术语只匹配独立词位，避免“己/自己”“子/例子”误标。
- locale 编译包保留双语 KU 共用运行格式；构建只清理旧内容包，保留 TS 产物。
- Fixture A 四柱按文档，解读用强弱、神煞和周期数值为手写示例。
