# B-16 · 日记与自我追踪

## 完成项
- 每日运势页底部「今天怎么样」：1–5 心情、可选一句话、保存与修改。
- JournalEntry：userId/profileId/date/mood/text/createdAt；每档案每天唯一。
- text 使用 AES-256-GCM、JournalEntry.text AAD 和用户 HKDF 子密钥；纳入密钥轮换。
- 数据库约束校验心情、密文与档案归属；账户删除和档案删除均清除日记。
- /me/journal 月视图、按月列表、日期跳转、预测总评与实际心情叠加。
- Mirror 统计：Pearson 相关性、当前/最长连续天数、命中最多领域（保留并列）。
- 首次记录保存预测快照，修改文字/心情或出生档案不会覆盖历史预测。
- JSON 账户导出增加解密后的 journalEntries；日志/Sentry 隐私过滤覆盖日记字段。
- zh/en 文案同时提供，zh-TW 经既有生成流程同步；账户导航增加入口。
- 修正现有登录用户运势日历的多档案种子，使日历与每日页使用同一预测。
- 一条 E2E 生命周期覆盖 zh/en × 桌面/375px 移动端，并检查加密、导出与删除。

## 未完成项
- 无。

## DESIGN-GAP
- 每个档案/民用日期仅一条；文字可选、单行且最多 500 字；可补记过去，禁止未来。
- 增加 prediction JSON，保存五维/总评、IANA 时区、profileVersion、engineVersion。
- 相关性需 ≥3 条且两变量均有变化；仅用于反思，不表示准确率或因果关系。
- 连续记录允许截至昨天；按民用日期计算，跨 DST 不会断档。
- 领域命中定义为该领域预测星级等于整体实际心情；没有独立领域结果输入。
- 日记 Server Actions 复用 daily 的 120 次/小时配额。
- 写入锁定账户行，与档案修改/删除和账户删除串行；外键校验档案用户一致。
- text 无 enc 前缀，扩展加密登记、AAD 白名单及密文查询/聚合保护。
- 数据库增加 mood 范围与密文格式 CHECK；档案删除级联清除日记。
- 新文案使用 journal.* 与 me.journal；统计口径通过原生 details 展开。
- 日记编辑手势不触发每日页左右切换，避免丢失未保存句子。
- 每日请求显式绑定日记的所属档案，防止其他标签页更换档案 cookie 后错配。
- 约束负例用 PGlite 直连 SQL，避免测试 Socket 协议连接被错误响应中断。
