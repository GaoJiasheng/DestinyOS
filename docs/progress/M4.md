## DESIGN-GAP
- 广告槽位映射新增公开环境变量；未知年龄/GPC 保守非个性化，18 岁所在年份继续未成年标记。
- 缺真实运营者身份/邮箱明确展示待配置，不虚构法律主体；新增 User.disclaimerAcceptedAt。
- Checkout 每用户/周期/10 分钟幂等；Portal 只依赖 secret；USD 默认建议价及脚本 cents 覆盖。
- 订阅按用户加事务锁并读取 Stripe 最新状态；未知/删除账户不恢复；缺邮件配置跳过提醒。
- 匿名反馈每晚分批正则脱敏；分享浏览数已直接入库，不另建 Redis 回写队列；系统审计不带目标 PII。
- CSP 新增 /api/v1/csp/report，借用反馈限流，故障丢弃遥测；静态页暂保持预生成；构建限制两 worker。
- 文档未指定署名页路径，采用 /credits，保留原 /about 页面。
- 文案命名空间改为一次扫描，防止全量百科构建重复二次复杂度扫描；保留原文案键。
- 白名单含 MPL/CC/OFL 等非 GPL/AGPL 许可证；个别推断许可证按固定包版本审核。
- 保留 next-intl 3 与 Node-only Vitest；5 个具体公告例外由 security:policy 验证适用性/补丁。
- extract-zip 无上游修复版本：补丁校验 symlink 目标并独占写文件；回归测试覆盖两个攻击路径。
- Git 的空白检查不检查 patch 数据文件，因为统一 diff 的空白上下文行必须保留一个空格。
- E2E 用进程预加载的 Stripe mock 与真实签名，不在生产应用加入支付绕过。
