# App M07：占卜仪式

完成项：
- 塔罗完整流程：八类牌阵与共享牌位缩略图、问题/类别/逆位、手势或按钮洗牌、拖切三叠与合并顺序、跳过切牌。
- 140° 扇形滑动浏览全部 78 张牌，每次仅挂载 25 张；手动选择和替抽、飞入牌位、600ms 3D 翻牌、金光/粒子、300ms 逆位旋转。
- 复用 Web 公版 RWS 牌面与 packages 的布局、seed/选牌算法、排盘、解读、内容及校验；原生界面不复制算法。
- 六爻加速度摇一摇与摇卦按钮等效，800ms 防抖、每次三枚结果驱动铜钱、物理弹跳、逐爻生成、动爻光环、本变卦翻转。
- 一键摇完串行 400ms/次；「问」弹层与推算页接入正式仪式。
- 梅花时间/报数/随机三法、农历钟表时显示、2–3 个 1–999 整数校验。
- 奇门当前/指定时刻、IANA 时区、出生时刻入口、类别、洛书九宫四层点亮与触感节拍。
- 所有展示结果与 SQLCipher 中英报告快照一致；私密问题不进入 URL/日志，牌面只含问题哈希；重试复用同一记录 ID。
- 音效默认关闭、触感默认开启，偏好加密持久化；expo-audio 遵循 iOS 静音键，不请求麦克风、不在后台播放。
- 原创合成 MP3/OGG 音效与生成脚本；洗牌、翻牌、铜钱、宫位、完成反馈各有音色与触感。
- next-intl zh/en 同步，繁中共享生成；动态字体、无障碍替抽/按钮、减少动效、低电量降级、后台/失焦取消、退出确认、保存失败重试。
- iOS 模拟器 Maestro 与截图；开发模式有限动画 display-link 采样仅记录帧间隔，不含个人输入。

未完成项 / 待验：
- Android 原生构建、Android 模拟器截图与 Maestro：按 Owner 要求留到 Java 环境就绪之后，本任务未安装 Java、未做 Android 原生构建。
- 真机摇动手感、实际触感与静音键听感，以及 GPU/真机帧率属于设备验收；模拟器不能证明硬件触感或 GPU 完成时间。

本次 DESIGN-GAP：
- 摇动阈值 2.2g，回落至 1.3g 以下重新武装，配合文档规定的 800ms 防抖。
- 奇门每层 300ms 分成九个约 33ms 宫位节拍，四层总时长约 1.2s。
- 未提供音效录音，采用可复现的原创程序合成，避免第三方采样许可。
- 公开 spread 参数可预选文档牌阵，非法值回退单张；不接收私密问题参数。
- 梅花揭卦被后台中断时显式继续原结果，不重新起卦。
- 开发帧间隔诊断测量 UI 调度，不替代 M14 的真机 GPU 性能验收。
