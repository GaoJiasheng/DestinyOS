## DESIGN-GAP
- schema 无 variant 字段，以 .a/.b ID 与双向 exclusive_with 表达变体；亮度分 supported/restrained 两组。
- 非命宫主星使用跨亮度正文与宫位级陷地修饰；修饰只陈述至少一颗匹配星，不推及全宫。
- 辅煞“关键宫”未穷举，采用命宫、官禄、夫妻；双星组合写实际可同宫的 24 种，加 6 个工作场景。
- 身宫采用引擎 isBodyPalace 的地支映射并保留 bodyPalaceBranch 依据；十二 schema 宫全写，当前排法仅达六宫。
- JSONPath-lite 不支持字段互比，运限四化穷举四化表真实星 key 与宫内主/辅星做关联。
- 五行局仅解释文档规定的排盘参数与起限年龄；格局沿用现有引擎谓词，不扩张成事件预测。
- 红鸾、天喜使用实际 adjectiveStars；只讨论自愿的愉快互动，不作婚育预测。
- schema 只有当前运限与本年，后三年描述为现实节点滚动复盘，不虚构未计算年份。
- 随机覆盖固定 seed=23、now=2026-10-04T00:00:00Z，出生年 1960–2025；不输出生日。
