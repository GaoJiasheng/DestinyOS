# B-06 · 运势日历

## 完成项

- `/[locale]/today/calendar`：SVG 金色月视图、五档总评与分数、月份切换。
- 日期与年度事件链接跳转 `/today?date=YYYY-MM-DD`，复用 `getDailyAction`。
- `getDailyRangeAction({ from, to, tz })`：最多 31 天，共用本命盘与日运评分逻辑。
- 引擎计算二十四节气、八字立春流年切换及大运交接。
- 引擎计算紫微农历新年流年切换及大限交接。
- 星历求水逆/金逆/火逆完整区间、新月满月、全球日月食峰值、个人太阳回归。
- Lahiri / Vimshottari 求 Mahadasha 与 Antardasha 切换，沿用 365.25 天/年。
- 年度 Redis 缓存按用户、年、档案版本、引擎版本、时区、语言隔离。
- 年度事件提供 zh/en 一句话解释和日期链接；用户可见文案经 next-intl。
- 登录档案仅在服务端解密；匿名档案留在设备本地计算，无出生信息上传。
- 加载、错误重试、缺档案、空列表、未知时辰与键盘日期访问。
- 未知时辰：八字/太阳回归/主运按正午估算；不显示紫微交接和吠陀次运。
- 无新增第三方依赖；引擎保持纯函数、显式时区与 TypeScript strict。

## 未完成项

- 无。

## DESIGN-GAP

- 新增年度事件数据 schema 与 calendar 文案命名空间，传数据键而非显示文本。
- 五档金色深浅使用现有每日星级阈值；月网格采用周一为首列。
- 年度事件另设 owner-only `getCalendarYearAction`，保持批量日运出参为分数。
- `getDailyAction` 支持 1900–2100，与日历和既有引擎范围一致。
- 年度缓存 TTL 为 24 小时，版本/时区变化直接使用新 key。
- 紫微沿用 iztro normal：出生地时区农历新年换流年与虚岁大限。
- 逆行按每日扫描括区间后求速度零点，保留跨年区间真实首尾。
- 日月食显示全球峰值，明确不代表当地可见。
