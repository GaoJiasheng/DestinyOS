## DESIGN-GAP 列表
- 七题使用透明主星/十神启发式，每项匹配 +2；尚无经验校准数据。
- 时段为软先验 +3，边界允许重叠，不剔除其余候选。
- 相似度按 31 分归一化；不确定计零，数值不代表出生时间概率。
- 十二民用时辰中点；子时选当天 00:00，晚子、时辰内边界与 DST 需人工核对。
- 真太阳时可能让民用候选标签与实际时柱不同，结果页明确展示。
- 空命宫借对宫主星；时辰一句话特征为观察提示而非核实时辰证据。
- 来源与相似度存在现有加密载荷，不新增明文数据库字段。
- 加密设备草稿跨路由传递出生信息；重试保留候选/体系幂等键。
- 档案手动事实编辑清除推测标记；页面总置信度以上述相似度为上限。
- 档案 API 的额外版本/名称字段进入引擎前，只取严格 BirthInput 字段。
- E2E 复用现有隔离生产数据库/邮件服务测试环境。
