## DESIGN-GAP
- 新增 session authenticatedAt、user lastActiveAt、feedback processedAt；迁移旧 session 为必须重新认证。
- KnowledgeRelease.bundles 保存不可变完整快照；首次发布归档随应用交付的版本，支持第一次编辑后回滚。
- EventDaily 用确定性分组 ID 处理可空维度；日界线固定 UTC，原始 SQL 显式 date，避免会话时区偏移。
- 07 无独立事件枚举，沿用 06 事件名并增加失败/注册/活跃/订阅结束；日哈希使用 AUTH_SECRET 派生盐。
- cron 重建已完成日期以纳入迟到事件，保留原始 Event；实时缓存故障由数据库计数兜底。
- Fixture 卜算使用固定时刻/地点/种子；路径校验复用 CI 冻结命盘。
- 发布展示已有知识库覆盖率缺口，仅阻止新增缺口；未擅自改写 M2 已交付语料。
- MRR 按币种、周期折月；不计税及一次性费用，试用计订阅人数但 MRR 为零。
- 公告范围采用公开路由前缀；维护模式允许认证确认，以便管理员恢复服务。
- 导出在邮箱随机 token 外要求本人 session，错误用户访问不消耗 token。
- Google re-auth 先撤销当前请求 session，避免 Auth.js 复用旧认证时间，其他 session 不受影响。
- 后台沿用公共视觉 token 与语义化 shadcn 表格/表单；管理员语言使用独立 cookie。
- 受控弹层记录实际外部触发按钮；表单仅换步时移焦点；同页锚点不触发离开确认。
- 无效分享页 lang 回退 zh；可信构建产物与已校验 Release 在文件/JSON 边界采用类型断言。
- PGlite 测试会话复用，测试连接使用 pgbouncer 模式关闭跨客户端预备语句缓存。
