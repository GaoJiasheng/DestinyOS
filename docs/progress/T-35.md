## DESIGN-GAP
- `cast?method` 使用 time/numbers/random/liuyao；meihua 兼容为 time。
- 私有 question record 传递起卦时区时刻与方法参数；不放入 URL。
- 匿名网络失败使用随页面加载的已编译知识库生成报告。
- 离线用原生 history 切到规定的本地报告 URL，避免请求新的 RSC 页面。
- 随机梅花的装饰铜钱使用第一个种子数模四呈现正面数。
- 未规定的仪式几何尺寸使用语义 CSS token。
- 共享 runner 使用两个测试 worker、30s 测试/60s 加载 hook；保留全部断言与 90% 覆盖率门槛。
- E2E 沿用真实 Prisma/Redis/Server Action 测试环境，使用生产构建与独立端口覆盖。
