# T-34 紫微组件 + 紫微报告页接入

## 完成项

- ZiweiGrid / ZiweiPalace：传统地支固定 4×4 方格盘、中宫摘要、移动缩略与宫位放大。
- 点击宫位：三方四正四宫高亮、SVG 三合三角与对宫连线、相关解读章节联动。
- 全屏弹层：焦点锁定、退出恢复、100–300% 滑块、双指缩放、拖动平移、重置。
- 主星/辅星/六煞/杂曜配色、生年四化角标、身宫标记、主星亮度。
- DecadalBar：按年龄排序的大限时间轴、年龄/年份区间、当前大限呼吸边框及四化。
- 流年开关：流年命宫与四化独立叠加，不覆盖生年四化。
- 报告页接入既有 engine → interpret → 匿名/持久化报告流程，专业视图含杂曜、十二神。
- 无时辰提示及恢复入口；阻止无时辰提交，保持引擎 E_REQUIRES_BIRTH_TIME。
- 所有新增可见文案经 next-intl，zh/en 同步；屏幕阅读器数据表与减少动效支持。
- 单元/流水线测试、zh/en 桌面/375px 移动 E2E、14 张命盘截图基线（0.5% 容差）。

## DESIGN-GAP

- 宫位到章节按 ziwei §6 主题映射；田宅/交友对应最相关章节。
- 文档未给英文名的辅助星/十二神采用通行拼音名称；缩略英文标签省略解释性后缀，详情与无障碍保留全称。
- 密度、全屏尺寸、100–300% 缩放范围扩展语义布局 token。
- 桌面长命盘栏独立滚动；全屏固定平移视口避免弹层压缩命盘，标题与关闭按钮独立于滚动正文。
- 截图暂时移除侧栏粘性和滚动限制，以完整捕获十二宫组件；固定字体使用统一路径供 macOS 与 Ubuntu CI 对比。
- E2E 复用本地 PostgreSQL/Redis/邮件替身，端口偏移隔离并使用生产构建避免 HMR；报告保存使用真实数据库会话 fixture，生产邮件策略不变。
- 两个完整知识库扫描与周易双语全量审计在覆盖率/共享 CPU 下限时 60 秒，断言及覆盖率阈值不变。
