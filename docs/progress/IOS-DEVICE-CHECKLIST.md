# iOS 真机检查清单（通知与小组件）

模拟器上已验证：7 天通知排程、测试通知送达与点按跳转、后台刷新函数、小组件三种尺寸与锁屏组件的显示。下面这些只能在真机上确认，请用 TestFlight 装最新构建后逐条检查。每条写了怎么做、看到什么算正常。

1. **首次授权**：删掉 App 重装，走引导到「每日提醒」页，点开启提醒。正常：先出现 App 自己的说明页，点了按钮才弹系统授权框；选「允许」后进入下一步，不会再弹第二次。
2. **每日通知按时到达**：「我 → 设置 → 每日推送」把推送时间改到 2–3 分钟后，回到桌面锁屏等待。正常：到点收到一条「天机」通知，标题和正文是中文，有档案时带今日星级与宜忌，没有档案时是一句引导语。
3. **点通知跳转**：点上一条通知（锁屏、通知中心各试一次）。正常：有档案时打开「今日」页并显示今日运势；没有档案时打开填写出生信息的页面。App 已在后台和完全退出两种情况都要试。
4. **关掉后不再推送**：在「每日推送」里关掉提醒，再把时间改到几分钟后。正常：到点不再收到通知；重新打开后又能收到。
5. **拒绝权限后的提示**：在系统「设置 → 通知 → 天机」里关掉通知（或首次授权时选「不允许」），回到 App 的今日页。正常：今日页出现提示卡片，带「去设置」和「关闭」；点「去设置」跳到系统设置里天机的页面；在系统设置重新打开通知后回到 App，提示消失。
6. **主屏小组件三种尺寸**：长按桌面 → 编辑 → 添加小组件 → 搜「天机」，分别添加小、中、大三个尺寸。正常：小号显示今日星级和幸运色；中号、大号另有一句提醒和五个维度，大号还有一张塔罗牌；文字不截断、不重叠，深色/浅色模式下都看得清。没有档案时显示「填上出生信息，看看今天的运势」。
7. **锁屏小组件**：长按锁屏 → 自定 → 锁屏 → 添加小组件 → 天机，加圆形和矩形各一个。正常：圆形显示星级，矩形显示星级加一句今日提醒；手机锁定状态下也能显示，不是空白。
8. **小组件跟随 App 更新**：在 App 里切换当前档案、换语言（中文 ↔ English）、在「每日推送」里改小组件主题。正常：回到桌面后几秒内小组件内容跟着变（档案、语言、主题都对得上）。
9. **跨天更新**：保留小组件过夜，第二天先不打开 App。正常：过了午夜小组件自动换成当天的内容，右上角日期对得上；不会一直停在前一天（数据预排 8 天，超过 8 天没打开 App 才显示「打开天机，更新今日运势」）。
10. **点小组件跳转与重启后**：点主屏小组件；然后重启手机，解锁前后各看一次小组件和第二天的通知。正常：点小组件打开「今日」页；重启后小组件仍有内容，第二天的通知照常到达。
