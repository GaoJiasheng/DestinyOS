## DESIGN-GAP
- 无档案示例使用合成成年生日，不持久化示例报告；刷新复用档案版本/日期/时区/引擎与知识版本身份。
- 同步引擎计算前让出一帧；日期区横滑采用 60pt/50pt 意图阈值，星空滚动 400pt 后保守停止动画。
- 原生学习页打包共享内容编译器当前输出至 Web resources 的同一公开产物，不复制编辑源。
- 无已授权地点使用已披露的 UTC 0° 星空；分享背景用确定性程序星点，不暴露位置或星空时间戳。
- 通知提示关闭状态存本机加密设置；Panchang 根据既往 Vedic 使用展开，等待设置覆盖。
- 广告同意与权益归 M13；当前预留位置且不请求广告。
- 复用已有统计约定：至少三组且有方差才计算 Pearson r；连续记录可截止昨天；维度命中是星级与总心情精确匹配，不能证明因果。
- 摘要先解析术语，再按句子/语言边界截断；分享卡英文按单词换行，二维码只指向公共页面；开发截图只操作专用合成记录，不删除其他档案。
