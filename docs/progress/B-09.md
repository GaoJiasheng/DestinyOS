# B-09 · 繁体中文 zh-TW

## 完成项
- next-intl、Locale、请求校验及 `/zh-TW` 路由支持第三种语言。
- `pnpm i18n:traditional` 用 opencc-js 1.4.2 的 cn→twp（s2twp）生成主字典、glossary、interpretation、tarot；接入 content:build。
- 术语覆盖统一軟體、體系、資料、資訊、登入、乾坤、斗數、羅睺及裡；保留 ICU 参数、术语键与 Markdown 目标。
- interpret 在输出层转换报告，缓存转换字符串；KU 源稿和编译包仍只保留 zh/en。
- 数据库复用简体报告快照，设备端另缓存繁体报告；语言切换不重排命盘、不污染 zh/en 快照。
- 导航、设置和分享页提供三种语言；账户、认证、每日运势、分享、导出及路由主题/广告识别支持繁体。
- 首页与百科提供 canonical、三语 hreflang、Open Graph；sitemap 与百科结构化数据覆盖 zh-TW。
- 两套屏幕字体各增加 1,340 个繁体字，维持按页 350KB 预算；补齐 OG/打印字体及繁体 PWA 离线页。
- 添加 Prisma Locale 映射与新增枚举值迁移；已有 reportZh/reportEn 字段不变。
- 一条 E2E 覆盖三语切换、路径/查询/锚点/cookie、SEO、羅睺百科、繁体报告及简繁往返，用 OpenCC 反向检查抽样。

## 未完成项
- 无。

## DESIGN-GAP
- 台湾术语及异体字采用固定覆盖表；裡按明确词组修正，保留地名/距离单位的里、命理乾字与體系。
- 转换缓存采用浏览器可用的 LRU：最多 2,048 项/100 万源字符，单项超过 10 万字符不缓存。
- Prisma 枚举用 zh_TW 映射数据库的 zh-TW；在应用边界还原 BCP 47。
- 补充字体保留原子集编号，新增每片八字的繁体子集，沿用既有按页体积上限。
- 切换语言完整载入目标文档，避免 Next.js 流式元数据保留旧 canonical；保留路径、查询与锚点。
- 忽略后台预取的语言 cookie，避免旧语言预取响应覆盖前台切换的偏好。
- 繁体验收使用独立端口生产服务与临时数据库/Redis，避免开发热更新干扰语言切换。
