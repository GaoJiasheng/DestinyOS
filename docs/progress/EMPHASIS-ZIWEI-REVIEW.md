# 紫微斗数「命盘侧重」复核材料（给外部命理顾问）

> 规则版本 scoringVersion 1.0.0 · 2026-11-19。规则原文在 `packages/content/ziwei/scoring.yaml`，附录由 `pnpm emphasis:calibrate --review docs/progress/EMPHASIS-ZIWEI-REVIEW.md` 生成。
> 这份材料不需要读代码。请您逐条看「规则表」和「断语一致性清单」，在第 5 节的问题上明确表态；附录里的 80 张盘用来抽查规则在真实盘面上的效果。

## 1. 这个功能在做什么

紫微斗数报告的概览里，会新增一块「命盘侧重」：看事业、财富、感情、人际四个领域，在这张盘里哪一块传统上更有支撑、哪一块更需要方法。

- 四个领域各看一个宫：事业 → 官禄宫，财富 → 财帛宫，感情 → 夫妻宫，人际 → 交友宫（仆役宫）。**疾厄宫不看**，界面上会写「本命盘不评估健康」。
- 每个宫按下面的规则累加一个分数，再和一般命盘比较，分成四档：**5 突出、4 有支撑、3 平稳、2 多花心思**。没有 1 档，也不显示数字和「x/5」。
- 分档不是绝对标准，而是和 2000 张随机命盘比：大约 20% 的宫落在 2 档、30% 在 3 档、30% 在 4 档、20% 在 5 档。
- 用户可以点开每一档，看到是哪几条规则在起作用（例如「官禄宫有巨门（旺），主星在这里发挥得比较顺……」）。负向的依据后面都跟着一句可以去做的建议。
- 界面固定写明：「侧重来自传统规则的组合，看的是这张盘里各领域的相对重心，不代表结果。」

## 5. 需要您明确表态的问题

1. **奴欺主**：交友宫（人际）分数很高时，传统有「交友宫太强反夺命宫之势」的说法。现在的规则是交友宫越强、人际档位越高，没有考虑这一点。是否需要处理？如果需要，条件和方向是什么（例如交友宫明显强于命宫时不再加分，还是只在文案里提示）？
2. **官禄宫的煞星**：擎羊、陀罗、火星、铃星、地空、地劫在官禄宫，是「激发、有冲劲」还是「阻碍、起伏」？现在按阻碍小幅减分（每颗 −0.25，最多 −0.75），与其他宫相同。是否应在官禄宫改为 0 分、减半，或分星处理（例如火铃算激发、空劫算阻碍）？
3. **亮度表流派**：现在用的是排盘库 iztro 的默认亮度表（附录 A 里庙旺合计约占一半以上）。您是否认可？如果您倾向中州派或其他表，请指出差异最大的几颗星，我们会重新标定分档。
4. 次要问题（有意见再写）：空宫借星打对折、对宫四化按半权，这两个权重是否合适？Z8a「财星居财位」是否只限武曲、太阴、天府，要不要加禄存或天府以外的星？
