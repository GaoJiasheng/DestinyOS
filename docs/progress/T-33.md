## DESIGN-GAP
- 四柱/关系图 SVG 用固定 viewBox，响应式尺寸扩展现有 4pt 布局 token。
- 圆环几何归一化引擎舍入后的百分比，文字保留快照数值。
- 身强弱超出标尺时仅截取指针位置，文字保留真实分数。
- 大运只展开快照包含的流年，无数据时显示空状态，不重算旧报告。
- 大运小数年龄显示一位小数，DOM data 属性保留精确年龄。
- 三合绘制三条边；六破沿用刑害的灰色点线。
- 依据定位最具体的已渲染父节点；无法定位时回退到命盘根节点。
- 过滤条件匹配多个节点时聚焦第一个，完整依据文本保持可见。
- 八字 E2E 独立端口 3033，避免其他工作树开发服务器干扰截图。
- 全量覆盖率测试使用单 worker，限制并发工作树中的峰值内存与 CPU 争用。
