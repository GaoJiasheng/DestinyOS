## DESIGN-GAP 列表
- enc* 的应用边界采用 UTF-8 JSON 字符串；持久化加密记录必须有 userId（匿名数据保持设备本地）。
- 嵌套关系写入采取拒绝策略，使用顶层事务；加密更新要求 where.userId 或 userId_version。
- 本地 Redis 用原子 sliding log，生产用 Upstash sliding window；Redis key 中身份先 SHA-256。
- IP 依赖部署代理覆盖 x-forwarded-for；缺失时共用安全 fallback bucket。
- HTTP 本地开发允许非 Secure Cookie；生产 Cookie 始终 Secure/HttpOnly/SameSite=Lax。
- 确认 Action 内部执行 Auth.js 回调并转移 Cookie，避免二次重定向使前端停留在回调 URL。
- PGlite 通过 PostgreSQL 协议、ioredis-mock 通过 RESP 暴露，应用本身不切换 mock 数据库客户端。
- PGlite 在新连接时清理共享 prepared statements；迁移生成使用独立 shadow 实例。
- 非生产 mock 邮件端点只允许 127.0.0.1；真实邮件仍使用 Resend。
- 健康检查独立探测最长 3 秒，依赖降级采用 HTTP 503。
- Sentry 完全移除 request headers/cookies，仅保留 user.id；browser DSN 单独公开、SDK 异步加载。
- 密钥轮换使用 raw Prisma、Serializable 事务，事务中重读避免覆盖并发编辑。
- E2E 使用两名浏览器 worker；语言协商测试隔离 Cookie，a11y 审计等待主题颜色过渡完成。
