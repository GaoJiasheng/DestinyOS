## DESIGN-GAP 列表

- 保持要求的 zi_unified→2 / zi_split→1 映射；用 Exact/Exact2 显式适配库真实日柱方向。
- §6 未定义辅助类型：采用英文/拼音键、柱位引用、角色及贡献明细；增加 features 严格对象。
- §3.5 要求但 §6 漏列的大运关系增加 `years[].relationsToLuck`。
- 得令优先本气生扶，中气同日主才 +1.5；月支正贡献已归得令，负贡献按普通藏干权重。
- 五行“少”取占比 <10%；中和无调候时五行均可喜；极弱取 ≤−6，无根指藏干无同五行。
- 复合特征 heavy 取 ≥3 个明/藏干出现次数；日干自身不计十神重数。
- 年龄为周岁折算的小数区间 [fromAge,toAge)；年份含部分覆盖年，debug 另列虚岁。
- 流年大运关系取当年立春时有效大运，童限/十步之外为空。
- 文昌采用现代通行表；学堂/词馆采用古本“官贵学堂/学堂会禄”日干表，避免伪造年纳音 basis。
- 羊刃用阳顺阴逆帝旺表，飞刃为对冲支；天罗地网用辰巳/戌亥支对简表。
- 魁罡完整核对四个日柱，因 schema 无 day_pillar，basis 标 day_branch。
- 增加 W_GENDER_DEFAULTED 与 W_SUSPECTED_CONG，对应文档指定的性别回退/疑似从格提示。
