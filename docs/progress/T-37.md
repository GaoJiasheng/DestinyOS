## DESIGN-GAP

- 行星错位采用对称环形松弛，跨 0° 边界保持间距，位置引线保持真实黄经。
- 无时辰轮盘将白羊 0° 锚定九点钟，避免虚构上升点。
- D9 度数按九次谐波黄经计算；无 Lagna 禁用北盘并保留南盘。
- 大运指针固定报告计算日期，不随客户端时钟悄悄改变。
- 宫位切换为只读预览，盘面/报告/元信息同步更新，不改写原始保存数据。
- 表单水合前禁用控件，避免原生勾选与 React 状态不一致。
- 占星侧栏解除粘性定位，使长盘面下方控件及表格始终可滚动触达。
- 测试服务允许独立端口；本任务 E2E 使用生产构建，避免开发脚本块加载异常。
- 生产测试进程预加载拦截 Resend 至本地邮件箱，应用生产代码不开放测试投递。
- 完整冷启动/登录/导入流程使用 240 秒时限。
- 整套知识库的两项集成扫描使用 30 秒时限，断言及覆盖率门槛不变。
- 截图记录表格实际滚动视口，排除浮动导航、开发指示器与日期相关说明。
- 日期指针存在性由独立断言验证。
