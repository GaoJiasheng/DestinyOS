## DESIGN-GAP

- UTC 零点重置，数据库独立日计数跨报告共享；删除历史保留计数。
- 新 API 使用 `/api/v1/readings/{id}/chat` 与 NDJSON delta/done/error；角色用 CHECK 限定字符串。
- 用显式派生白名单及本地已知身份/常见格式脱敏补充现有 stripPII；在 JSON 转义前逐段脱敏；界面提示勿填写身份资料。
- 单次 60 秒，最多两次尝试；401/403/400/404 不重试，已输出文本不重试。
- 实测国内站可能没有 `[DONE]`，要求 finish_reason 与 usage 后才接受 EOF。
- 限定官方 HTTPS 主机；思考内容与最终答案分离，不展示思考过程。
- 上下文 ≤ 100,000 字符、最近 12 条历史；面板显示最近 500 条，全部可导出/删除。
- 成功后原子保存两条消息；user tokens 含完整 prompt，assistant tokens 含模型思考。
- 60 请求/小时；阅读锁 180 秒；UI 复用报告卡片与现有设计 token。
- E2E 使用隔离凭证的进程预加载 provider mock；单一 preload 兼容 Next.js --import 归一化。
- 服务端运行时变量经 Turbo passthrough 保留；提示词纳入 Next.js 文件追踪。
