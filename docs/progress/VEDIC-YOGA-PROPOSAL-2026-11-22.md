# 吠陀四种常见瑜伽的收紧方案（2026-11-22）

> 性质：方案文档，没有改任何产品代码。数字来自新增的只读统计脚本 `packages/content/scripts/vedic-yoga-stats.ts`（引擎 0.4.1，2000 张随机盘，跑法见 §4.1）。写法参照 2026-11-17 Kemadruma 的修改（提交 `987c8c2`）。

**本文用到的术语**（第一次出现时也会括注）

| 术语 | 意思 |
|---|---|
| 瑜伽（Yoga） | 吠陀占星里对特定行星组合的命名，类似八字的「格局」 |
| 星座 / 同座 | 吠陀用恒星黄道的 12 个星座，「同座」指两颗星落在同一个星座里（不要求度数接近） |
| 宫、整宫制 | 以上升星座为第 1 宫，依次数 12 宫，一个星座就是一个宫 |
| 角宫（Kendra） | 第 1、4、7、10 宫，传统上最有力的位置 |
| 三方宫（Trikona） | 第 1、5、9 宫，传统上最吉的位置 |
| 凶宫（Dusthana） | 第 6、8、12 宫 |
| 宫主 | 某宫所在星座的守护星，例如上升白羊时第 1 宫主是火星 |
| 尊贵（dignity） | 行星所在星座的「得力程度」：入旺、本垣三方（moolatrikona，度数限定的强势区间）、自宫、友宫、中性、敌宫、落陷 |
| 焦伤（combust） | 行星离太阳太近、被阳光「烧掉」，传统认为力量大减。引擎的门限：水星 14°（逆行 12°）、木星 11°、金星 10°（逆行 8°）、火星 17°、土星 15°、月亮 12° |
| 相照（drishti） | 吠陀的星座相位：所有行星照第 7 个星座，火星另照 4、8，木星另照 5、9，土星另照 3、10 |
| 正午盘 | 不知道出生时间时按当地 12:00 排的盘，没有上升和宫位 |

## 0. 结论摘要

| 瑜伽 | 现状（现行规则 → 命中率） | 推荐 | 新命中率（有时辰 / 正午盘） |
|---|---|---|---|
| Gajakesari 象狮 | 木星在月亮起算的 1/4/7/10 个星座 → 34.8% | **G1**：再要求木星不落陷、不在敌宫、不焦伤（BPHS 原文附带的条件） | **18.1% / 18.0%** |
| Budha-Aditya 日水 | 日水同座 → 51.4% | **B1**：再要求水星不焦伤（离太阳 ≥ 14°，逆行 ≥ 12°） | **20.3% / 20.4%** |
| Raja 王者 | 角宫主与另一颗三方宫主同座 → 55.1% | **R1**：这一对主星都不落陷、不焦伤，且同座的宫不是 6/8/12 | **23.9%**（正午盘不判定，同现行） |
| Dhana 财富 | 2/11 宫主与另一颗 5/9 宫主同座 → 35.0% | **D1**：与 R1 同一条过滤 | **13.9%**（正午盘不判定） |

1. **目标区间定为单个瑜伽 10%–25%。**同一个引擎里，五种 Mahapurusha（大人物瑜伽）各 4.8–9.6%，属于少见的强格；这四种在传统里本来就是「常见但要看质量」的组合，可以比 Mahapurusha 常见一档，但不应超过四分之一的人。低于 10% 就和 Mahapurusha 没有层次差别，而且瑜伽一章只剩兜底段落的人会太多（见第 4 条）。
2. **四个推荐选项都只用引擎现有字段**（`sign`、`house`、`dignity`、`combust`），不用新增数据，也不需要相位模型。象狮和日水的推荐规则与出生时间无关，正午盘和有时辰盘的结果一致。
3. **为什么这么常见，原因都很具体**：日水同座的盘里 60.4% 的水星是焦伤的（水星离太阳最远 27.7°，中位数 16.1°）；象狮命中的盘里 43.2% 的木星在落陷或敌宫；Raja 命中的盘平均有 1.72 对同座主星，其中 26.3% 只是太阳、水星、金星这三颗总挨在一起的星凑成的。推荐选项正好针对这些原因。
4. **整体效果**：四种合计，平均每盘从 1.76 个降到 0.76 个；四种都不中的盘从 12.9% 升到 47.1%；十二种瑜伽一个都不中（报告的「瑜伽格局」一章只显示兜底段落）从 5.9% 升到 23.1%。如果四种都选「从严」档，这个比例会到 32.5%。
5. **改动量约 1.5–2 人日**：引擎 `yogas.ts` 四处条件 + 测试、四条知识单元中英文案、文档与参考数据重生成。端到端截图不会变（瑜伽不在 `#chart-root` 截图区域里，Kemadruma 那次也没有更新基线）。
6. **两端不一致**：iOS 1.0.0（构建 4）内置引擎 0.4.0，本来就和网页的 Kemadruma 不一致。建议网页先上，和 Kemadruma 一起进 App 的下一个构建。写本文时工作区里 `apps/mobile/app.config.ts` 有未提交的 1.0.1（构建 5）改动，说明下一个构建已在准备：要赶上它，这次改动需在构建 5 打包前合入；赶不上就进构建 6。在 App 带上新引擎之前，知识包不要单独推给 App（新文案描述的条件与 App 里的旧引擎不符）。

## 2. 现行判定（代码事实）

代码在 `packages/engine/src/astrology/yogas.ts`，`detectYogas(bodies, lagna)`。`relative(a, b)` 是 a 所在星座从 b 所在星座数起的序号（1–12），`kendra(n)` 判断 n 是否为 1/4/7/10。

| 瑜伽 | 现行条件（代码原样的意思） | `YOGA_CONDITIONS` 标识 | 正午盘 |
|---|---|---|---|
| Gajakesari | `kendra(relative(jupiter, moon))`：木星在月亮起算第 1、4、7、10 个星座 | `jupiter_in_kendra_from_moon` | 照常判定 |
| Budha-Aditya | `sun.sign === mercury.sign` | `sun_mercury_same_sign` | 照常判定 |
| Raja Yoga | 依次取第 1、4、7、10 宫主与第 5、9 宫主，两颗星不同且 `sign` 相同，命中第一对就停 | `distinct_kendra_trikona_lords_conjoined` | 不判定（需要上升） |
| Dhana Yoga | 同上，第 2、11 宫主与第 5、9 宫主 | `wealth_trine_lords_conjoined` | 不判定 |

注意两点：

- Raja 的「两颗星不同」意味着一颗星同时管角宫和三方宫（yogakaraka，瑜伽主星，例如上升金牛的土星管 9、10 宫）**不算** Raja。样本里 50.1% 的盘有 yogakaraka（由上升星座决定，12 个上升里有 6 个有）。这一点本方案不动。
- 经典的 Raja、Dhana 还包括互照（两星互相相照）、互换（各在对方守护的星座）、一星在另一星的宫里。引擎只用了同座这一种。本方案只收紧同座，不增加其他关系（增加会让命中率回升，而且需要相位模型）。

## 3. 逐个瑜伽

每个选项都标明：判定条件（能直接写代码）、依据、需要的引擎字段、命中率。命中率是 2000 张有时辰盘 / 同一批人的正午盘。

### 3.1 Gajakesari（象狮瑜伽，月亮与木星）

**为什么常见**：木星在月亮起算 12 个星座里的 4 个，随机情况下就是 1/3；样本 34.8%，四个位置各占 22–29%。经典条件里「木星不能落陷、焦伤、在敌宫」被省掉了，而命中盘里 43.2% 的木星在落陷（摩羯）或敌宫（水星、金星守护的双子、处女、金牛、天秤），7.0% 焦伤。

**经典与现代做法**

- BPHS（《帕拉夏拉占星大全》）讲各类瑜伽的章节：木星在上升或月亮的角宫，与吉星同宫或受吉星相照，**且不落陷、不焦伤、不在敌宫**，为 Gajakesari。原句大意如此，章号和逐字译法需顾问核对。
- Phaladeepika（《果报明灯》）第 6 章、Saravali（《精华集》）的写法较简单，只要求木星在月亮的角宫（需顾问确认这两部书是否附带强弱条件）。
- 现代书（如 B. V. Raman《三百种重要组合》）把它列为第一条，同时提醒这条组合很常见、要看木星和月亮的强弱（大意，需核对原文）。
- 「月亮有力」的通行判断是月亮不落陷（天蝎）、不是残月：离太阳不到 72°（Paksha Bala，月相力）视为弱。72° 这个界限是现代通行做法，需顾问确认。
- BPHS 的「从上升或月亮起算」会让命中变多（两种起算任一满足），不建议采用。

**选项**

| 选项 | 判定条件（代码） | 依据 | 字段 | 命中率 |
|---|---|---|---|---|
| G0 现行 | `kendra(relative(guru, chandra))` | Phaladeepika 简式 | `sign` | 34.8% / 34.4% |
| **G1 木星有力** | G0 且 `guru.dignity !== 'debilitated' && guru.dignity !== 'enemy' && !guru.combust` | BPHS 原文附带的「不落陷、不焦伤、不在敌宫」 | `sign`、`dignity`、`combust`（都已有） | **18.1% / 18.0%** |
| G2 月亮有力 | G0 且 `chandra.dignity !== 'debilitated' && distance(chandra.sidLon, surya.sidLon) >= 72` | 现代月相力做法 | `dignity`、`sidLon`（已有；`distance` 在 `math.ts`） | 18.9% / 19.1% |
| G3 吉星相助 | G1 且水星或金星与木星同座，或按星座相位照到木星 | BPHS「与吉星同宫或受吉星相照」 | **缺相照**：引擎没有 graha drishti，要在 `yogas.ts` 里补一个按星座的相照函数（约 10 行） | 5.3% / 5.4% |
| 组合 G1+G2 | G1 且 G2 | — | 同上 | 9.0% / 9.3% |
| 组合 G1+G2+宫 | G1+G2 且木星不在 6/8/12 宫（正午盘跳过） | 现代做法 | `house` | 6.9% / 9.3% |

**推荐 G1。**条件全部来自 BPHS 同一句话，引擎字段现成，有时辰和正午盘几乎一样（18.1% 对 18.0%），落在目标区间中部。G3 是 BPHS 完整版，但 5.3% 太少、还要新写相位；G2 的 72° 没有经典明文，可以作为以后的「从严」档。

**注意**：「敌宫」用的是引擎现有的天然友敌表（木星的敌星为水星、金星）。有的流派用天然 + 临时关系合成的五重友敌（Panchadha），结果会不同，需顾问确认用哪一种。Fixture A（上升双子、月亮射手、木星双子）的象狮会因此消失（木星在敌宫），影响见 §5.3。

### 3.2 Budha-Aditya（日水瑜伽，太阳与水星）

**为什么常见**：从地球看，水星离太阳最远约 28°（样本最大 27.7°，中位数 16.1°），两者在同一个星座的机会本来就过半，样本 51.4%。而同座的盘里有 60.4% 的水星离太阳不到 14°，按引擎自己的规则就是焦伤。现行文案甚至专门写了一句「同座也不自动表示水星没有焦伤」。

**经典与现代做法**

- 日水同宫的结果在 Saravali、Brihat Jataka（《大本命书》）讲两星合相的章节里有描述（聪明、能干、善言），但「Budha-Aditya Yoga」作为独立名称多见于后世和现代书；有的书称 Nipuna Yoga（需顾问确认出处）。
- 现代通行的保留条件：水星不焦伤（最常见的一条）；水星不落陷（双鱼）；落在吉宫（角宫或三方宫）效果更好、在 6/8/12 宫减弱。
- 另有一种说法认为水星「不怕焦伤」，所以日水同座照算。这与「焦伤即失力」的通则冲突，本方案不采用，但需顾问表态（§6 第 3 条）。

**选项**

| 选项 | 判定条件（代码） | 依据 | 字段 | 命中率 |
|---|---|---|---|---|
| B0 现行 | `surya.sign === budha.sign` | — | `sign` | 51.4% / 51.3% |
| **B1 不焦伤** | B0 且 `!budha.combust` | 现代通行；焦伤即失力的通则 | `combust`（已有，门限 14°/逆行 12°） | **20.3% / 20.4%** |
| B2 不落陷、不在凶宫 | B0 且 `budha.dignity !== 'debilitated' && surya.dignity !== 'debilitated'`，且（有时辰时）`![6, 8, 12].includes(budha.house)` | 现代通行 | `dignity`、`house` | 31.4% / 42.8% |
| B3 吉宫 | B0 且（有时辰时）`[1, 4, 5, 7, 9, 10].includes(budha.house)` | 现代通行 | `house` | 24.1% / 51.3%（正午盘跳过宫位就等于现行） |
| 组合 B1+B2 | B1 且 B2 | — | 同上 | 12.3% / 16.9% |
| 组合 B1+B3 | B1 且 B3 | — | 同上 | 9.3% / 20.4% |

**推荐 B1。**它直接对准常见的原因（六成是焦伤），一句话能说清（「水星离太阳 14° 以上」），与出生时间无关。20.3% 在目标区间偏上，但日水本来就是这四种里最「日常」的一种。若希望更少，用 B1+B2（12.3%），代价是正午盘和有时辰盘差 4.6 个百分点。B3 在正午盘上没有意义，不推荐。

### 3.3 Raja Yoga（王者瑜伽，角宫主与三方宫主）

**为什么常见**：要检查 4 个角宫主 × 2 个三方宫主，最多 8 对，只要有一对同座就算。七颗行星分在 12 个星座，任两颗同座的机会本就不小，太阳、水星、金星又总在 48° 以内挤在一起。样本 55.1%，命中的盘平均有 1.72 对同座主星；26.3% 的命中只由日、水、金组成，而这种情况下水星或金星往往是焦伤的。

**经典与现代做法**

- BPHS 讲 Raja Yoga 的章节：角宫主与三方宫主发生关系（同宫、互照、互换）即成；第 9、10 宫主的组合最重要（Dharma-Karmadhipati，法业宫主）。同一章还说：如果第 9、10 宫主同时管第 8 或第 11 宫，仅仅有关系并不成格（原句大意，需核对）。
- 通则（BPHS 与 Phaladeepika 第 6 章末尾都有类似说法，需核对原文）：成格的行星落陷、焦伤或落在凶宫，瑜伽不起作用或大打折扣。
- 度数接近：经典按星座判定，没有容许度；现代很多人认为同座且相距 10° 左右以内才算紧密合相。这一条没有经典依据。

**选项**（`a`、`b` 是同座的一对主星；同座时它们在同一宫）

| 选项 | 判定条件（代码） | 依据 | 字段 | 命中率 |
|---|---|---|---|---|
| R0 现行 | 存在一对 `a.key !== b.key && a.sign === b.sign` | BPHS 同宫关系 | `sign` | 55.1% |
| **R1 不受损** | 存在一对同座主星，且 `clean(a) && clean(b)`，其中 `clean = (x) => x.dignity !== 'debilitated' && !x.combust && ![6, 8, 12].includes(x.house)` | 「成格星受损则不成」的通则 | `dignity`、`combust`、`house`（都已有） | **23.9%** |
| R2 紧密 | 存在一对同座主星，且 `distance(a.sidLon, b.sidLon) <= 10` | 现代做法 | `sidLon` | 32.9% |
| R3 有尊贵 | 存在一对同座主星，且至少一颗 `dignity` 为 `exalted`/`own`/`moolatrikona` | 现代做法 | `dignity` | 24.9% |
| R4 排除 8/11 宫主 | 存在一对同座主星，且两颗都不兼管第 8 或第 11 宫（第 1 宫主除外） | BPHS 对 9、10 宫主的说法，推广到所有组合 | 宫主归属（由 `lagna.sign` + `VEDIC_LORDS` 算，或 `houses[].lord`） | 44.7% |

| 组合 R1+R4 | 同一对同时满足 R1 和 R4 | — | 同上 | 18.6% |

**推荐 R1。**三条都属于「成格的星本身不能坏」的通则，经典和现代都认，字段现成；23.9% 在目标区间上沿，与 Raja 作为一大类组合的地位相称。施工时注意：现在的 `conjoined` 命中第一对就返回，改后要「返回第一对**合格**的」，报告里列出的两颗星会随之变化。如果 owner 想让 Raja 更稀有，用 R1+R2（13.0%），但要在文案里说明「相距 10° 以内」是本站采用的现代标准。

### 3.4 Dhana Yoga（财富瑜伽，2/11 宫主与 5/9 宫主）

**为什么常见**：2 × 2 最多 4 对，原因同 Raja。样本 35.0%，命中盘平均 1.28 对；19.8% 只由日、水、金组成。

**经典与现代做法**

- BPHS 讲 Dhana Yoga 的章节：第 1、2、5、9、11 宫主之间相互联系即主财；另有大量具体星位的财格（例如某星在第 5 宫自宫并受第 11 宫主相照），本期不实现。
- Phaladeepika 第 6 章也列有财格，并强调成格星需有力（需核对）。
- 「受损则不成」的通则与 Raja 相同。

**选项**

| 选项 | 判定条件（代码） | 依据 | 字段 | 命中率 |
|---|---|---|---|---|
| D0 现行 | 第 2/11 宫主与第 5/9 宫主中存在不同的两颗同座 | BPHS | `sign` | 35.0% |
| **D1 不受损** | 同 R1 的 `clean(a) && clean(b)` | 通则 | `dignity`、`combust`、`house` | **13.9%** |
| D2 紧密 | 同座且相距 ≤ 10° | 现代做法 | `sidLon` | 20.3% |
| D3 有尊贵 | 同座且至少一颗入旺/自宫/本垣三方 | 现代做法 | `dignity` | 16.8% |
| 组合 D1+D2 | 同一对满足 D1、D2 | — | 同上 | 6.2% |
| 组合 D1+D3 | 同一对满足 D1、D3 | — | 同上 | 7.0% |

**推荐 D1。**和 Raja 用同一个过滤函数，代码和文案都能共用一句话；13.9% 在目标区间内。两个组合都跌到 7% 以下，接近 Mahapurusha 的稀有度，不推荐。

### 3.5 推荐规则的代码形态（供施工直接参照）

```ts
// gajakesari: BPHS adds that Jupiter must not be debilitated, combust or in an enemy's sign.
const strongJupiter =
  jupiter.dignity !== 'debilitated' && jupiter.dignity !== 'enemy' && !jupiter.combust;
if (kendra(relative(jupiter, moon)) && strongJupiter) add('gajakesari', [moon, jupiter]);
// budha_aditya: a combust Mercury (within 14°, 12° retrograde) does not form the yoga.
if (sun.sign === mercury.sign && !mercury.combust) add('budha_aditya', [sun, mercury]);
// raja/dhana: both lords unafflicted (not debilitated, not combust) and outside houses 6/8/12.
const clean = (b: Body) =>
  b.dignity !== 'debilitated' && !b.combust && !(b.house !== null && [6, 8, 12].includes(b.house));
// in conjoined(): if (a.key !== b.key && a.sign === b.sign && clean(a) && clean(b)) { add(...); return; }
```

`YOGA_CONDITIONS` 建议改为：`jupiter_in_kendra_from_moon_not_debilitated_enemy_or_combust`、`sun_mercury_same_sign_mercury_not_combust`、`distinct_kendra_trikona_lords_conjoined_unafflicted_outside_dusthana`、`wealth_trine_lords_conjoined_unafflicted_outside_dusthana`。这些字符串会出现在计算接口的 `debug.yogaConditions` 里（`packages/engine/src/index.ts`），没有别处依赖。

### 5.2 知识单元守卫（Q8 的建议）

# vedic.yoga.budha_aditya
when:
  all:
    - path: yogas[*].key
      eq: budha_aditya
    - path: bodies[key=budha].combust
      eq: false
# vedic.yoga.gajakesari
when:
  all:
    - path: yogas[*].key
      eq: gajakesari
    - path: bodies[key=guru].combust
      eq: false
    - not:
        path: bodies[key=guru].dignity
        in: [debilitated, enemy]

## 6. 需要吠陀顾问确认的事项

1. **象狮的 BPHS 原文**：「不落陷、不焦伤、不在敌宫」是否原文就有、章号、「敌宫」用天然友敌还是五重友敌（Panchadha）。Phaladeepika、Saravali 是否附带强弱条件。
2. **月亮有力的界限**：离太阳 72° 是否合适（还是 90°、上弦后才算），落陷是否单独排除。只影响从严档 G2。
3. **日水与焦伤**：是否接受「水星焦伤则日水不成」；对「水星不怕焦伤」一派怎么处理；焦伤门限用 14°（逆行 12°）是否合适。
4. **「Budha-Aditya」的出处**：经典里是否有这个名字（或 Nipuna Yoga），文案里能不能说「传统」。
5. **Raja 的 8/11 宫主例外**：BPHS 原句只针对 9、10 宫主，还是可以推广到所有角宫主与三方宫主组合；第 1 宫主是否豁免。只影响 R4。
6. **受损通则**：成格星「落陷、焦伤、在 6/8/12 宫」不成格，三条是否都成立；落陷但有 Neecha Bhanga（落陷解除）时要不要恢复；逆行是否另算。
7. **紧密合相的容许度**：Raja、Dhana 用 10° 是否合理。只影响从严档。
8. **Dhana 的范围**：是否应把第 1 宫主也算进来（BPHS 讲 1、2、5、9、11 宫主），加进来命中率会回升。本方案没有加。
