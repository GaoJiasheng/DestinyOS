# CHAT-EVAL · 追问大师质量评估与调优

## 完成项
- 40 题（zh/en 各 20），覆盖事业、感情、健康/投资边界、流年、合盘、塔罗及辱骂/越权/生日套取。
- Fixture A 四体系实测；`test-results/chat-eval/` 保存 160 条归档对话、四份真实批量响应及去标识化上下文。
- 六维等权 0–2 rubric：基于命盘、不编造、不越界、语气、长度、语言；脚本检查与模型评分分开记录。
- 初轮 MiniMax 自评与自动检查均分 11.925/12；8 个配对基线 11.5→12，归档 Codex 复核均分 11.9125/12。
- 系统提示明确单人合盘限制、无行运/流年时的证据边界、实际牌位与逆位、隐私和专业建议边界。
- 仅带最多两个相关章节及最近三轮对话；塔罗事业/金钱问题补入逐牌章节，保留完整 JSON 与命盘事实。
- 本地拒绝保护：56/56 对抗组合明确拒绝；含医疗/投资共 72 组不调用 provider，拒绝记录 tokens=0。
- 更新建议问题、120 字超限、UTC 配额及恢复文案；zh/en 同步并生成 zh-TW，全部使用 next-intl。
- 校验完整短答后释放 NDJSON，移除格式标记、保留完整句子、翻译已知章节标签、错误语言返回恢复提示。
- 隔离 Playwright 输出及并行工作树端口；真实 smoke 改为显式启用，普通单测不消耗真实调用预算。
- 新增开发依赖 jsonrepair 3.15.0（ISC），仅修复响应 JSON 语法；无新增 AGPL/GPL 依赖。

## 请求、token 与成本
- 已确认 198 次真实请求；计入最多 2 次无法核实的早期 smoke，上界为 200；已停止追加调用。
