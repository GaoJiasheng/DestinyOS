# 01 · 产品需求文档（PRD）

## 1. 目标用户与场景

### 1.1 画像

| 画像 | 描述 | 典型诉求 | 设计含义 |
|---|---|---|---|
| P1 海外华人上班族（25–45） | 在北美/澳洲/欧洲生活，中文母语，英文流利，对八字、紫微有文化亲近感但不懂术语 | 看每日运势、年运、婚姻事业大方向；想要一份"能读懂"的命盘报告 | 中文优先、术语白话化、每日功能要快 |
| P2 二代华裔 / 配偶（20–40） | 英文为主，对东方命理好奇 | 用英文读懂自己的八字和紫微；塔罗、星座是日常娱乐 | 英文版不能是机翻味，术语要有解释 |
| P3 命理爱好者 | 会自己排盘、有流派偏好，会挑错 | 想要专业排盘图、原文引用、流派说明 | 排盘必须准确，流派可见，提供"专业视图" |
| P4 路人（分享链接进来） | 被朋友的分享卡片吸引 | 30 秒内算一个自己的 | 无需登录即可试算，试算后引导注册保存 |

### 1.2 核心场景

1. **首次体验**：进首页 → 选体系或直接"开始推算" → 填出生信息（可不登录） → 看报告 → 被提示"登录后保存，明天看运势" → Google 登录 → 档案保存。
2. **日常回访**：登录用户每天打开 `/today` 看今日运势（综合五项评分、宜忌、幸运元素、今日塔罗、星象提示）。
3. **深入研读**：从报告概览进入某一章节（如八字的"事业与财富"）阅读长文，展开古文引用和规则说明。
4. **即时占卜**：心里有事 → 塔罗抽牌或梅花起卦 → 得到针对该问题的解读 → 保存到历史。
5. **分享**：报告页点"生成分享卡" → 选样式 → 下载图片或复制链接。
6. **去广告**：免费用户看到广告 → 升级页 → Stripe 订阅 → 全站无广告。
7. **隐私管理**：设置页查看数据、导出 JSON、删除账户。

## 3. 非功能需求

| 项 | 要求 |
|---|---|
| 性能 | 移动端首页 LCP ≤ 2.5s（4G）；报告页 TTI ≤ 3.5s；排盘计算单体系 ≤ 200ms（服务端）；Three.js 场景在中端手机 ≥ 45fps，低端自动降级 |

| 浏览器 | 最近两个大版本 Chrome/Safari/Firefox/Edge；iOS Safari 16+；Android Chrome 110+ |
| 可维护性 | 引擎单元测试覆盖 ≥ 90%；每个体系 ≥ 20 条黄金用例 |

## 4. 关键用户流程

### 4.1 首次推算流程（匿名）

```
首页
 └─ 点击任一体系卡片 / "开始推算"
     └─ 出生信息表单（步骤 1/2：日期时间；步骤 2/2：地点与性别）
         ├─ 不知道时辰？ → 勾选 → 说明影响（八字缺时柱、紫微需时辰不可算、占星无宫位）
         │                 → 紫微提供"尝试 12 个时辰里最像你的"（二期），一期显示提示并禁用紫微
         └─ 提交 → 全屏"推演中"动效（1.2–2.0s，实际计算远快于此，动效为仪式感且做最小时长）
             └─ 报告页（概览 → 章节）
                 ├─ 顶部提示条："登录保存这份报告，并解锁每日运势"
                 └─ 右下角分享按钮
```

### 4.2 登录与档案绑定

```
点击登录 → 选择 Google / 邮箱
 ├─ Google：OAuth → 回调 → 若本地有匿名档案与报告 → 询问"导入到账户？" → 导入
 └─ 邮箱：输入 → 发送链接 → 点击 → 同上
登录后若无档案 → 引导到 /me/birth
```

### 4.3 每日运势

```
/today
 ├─ 未登录 → 展示示例 + 登录引导（允许匿名用本地档案看，但标注"未保存"）
 ├─ 已登录无档案 → 引导填档案
 └─ 已登录有档案 → 读取或生成当日缓存（key: userId + localDate + profileVersion）→ 渲染
```

### 4.4 删除账户

```
/me/settings → 危险区 → "删除账户" → 弹层要求输入 DELETE → 调用 API
 → 立即：会话失效、档案与报告标记 deletedAt、公开链接失效
 → 7 天后：定时任务物理删除
 → 邮件确认（可选）
```

## 5. 内容深度要求

每个体系的完整报告由固定章节组成（各体系文档给出章节表）。通用要求：

- **概览章**：300–500 字，三句话总结 + 五维评分雷达图 + 三个关键词。
- **每个正文章**：400–900 字。结构：结论段 → 依据段（指出命盘中哪些要素导致该结论，用高亮链接回排盘图）→ 生活化举例 → 建议 2–3 条 → 可展开的「原文与规则」。
- **术语卡**：正文里的术语带下划线虚线，点击弹出 ≤ 60 字的白话解释（来自 glossary）。
- **强度标签**：每条结论带强度（强/中/弱），对应知识库单元权重，UI 用不同透明度区分。
- **两套语言各自成文**，不是逐句翻译；英文版术语附拼音与简短解释（如 "Day Master (日主, rì zhǔ)"）。

## 6. 非目标与明确排除

- 不承诺预测准确性，不做任何"改命""化解"收费服务，不卖实物。
- 不提供医疗、法律、投资建议；相关章节只谈"倾向"和"注意"。
- 不采集通讯录、位置权限（出生地由用户手动搜索输入）。
- 不做社区、评论、私信。
- 不做 AI 对话（一期）。
