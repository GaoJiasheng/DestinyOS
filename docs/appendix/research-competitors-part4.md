## 逐产品要点

### 灵机文化（linghit.com）/ 顺历
- 官网无在线工具，主要收入为真人咨询师服务（首页有防伪与咨询师核验）。旗舰 App「顺历」把每日运势与黄历、日程绑定：功能卡「每日运势、每日宜忌、吉神罗盘、时辰凶吉、日程记事、节日神诞」；每日运势需先绑定八字，呈现为「工作、财运、感情、身体的凶吉得分 + 状态分析」。用户反馈：黄历文言门槛高、凶吉结果「触目惊心」、广告多。会员 ¥18/月 … ¥888/年高级。来源 https://apps.apple.com/cn/app/id1476686022 、https://www.woshipm.com/evaluating/200655.html

### 测测 cece
- 对外口径「心理情感 AI 问答社区」（合规），实际首页九宫格含星座、星盘、缘分合盘、沙盘、AI 玩法。底部 5 Tab，中央「问」为 AI。会员 ¥25/月（首月 ¥9.9）、¥178/年；测测币；真人达人 1v1 咨询。5500 万注册，女性 75–85%，18–35 岁，晚 7 点后活跃。短板：多 AI 入口并列认知负担高、AI 无长期记忆。来源 https://apps.apple.com/cn/app/id756771906 、https://www.woshipm.com/evaluating/6391148.html

### iztro / ziwei.pub（中文圈体验最好的排盘交互）
- 新建命盘表单：阳历/农历分段按钮；生日选择器；**时辰下拉 13 档（早子时 00:00–01:00 … 晚子时）**；性别；名字可选。**「不知道出生时辰？帮你定盘」→ 辅助定盘问卷**（大致时段：白天 / 晚上 / 深夜凌晨 / 其他 / 不确定）推荐最可能时辰并声明仅供参考。无真太阳时选项。来源 https://ziwei.pub/astrolabe/?mode=new 、https://ziwei.pub/rectification
- 结果页：顶部命盘摘要 + 「新建 / 收起 AI / 全屏」；**运限切换条「−10年 −1年 −1月 −1日 −1时 [日期][时辰] +1时 … +10年 今日」**；十二宫方盘每宫显示主星亮度、辅煞杂曜、运限飞星（运陀、流禄、大限·乙、流年·丙…）、长生/博士十二神、大限年龄段、小限序列；中宫基本信息（五行局、四柱、命主身主、命宫身宫）；右侧 AI 问盘面板。**URL 参数即命盘**，天然可分享。全站无广告。视觉：浅紫渐变 + 玻璃拟态 + 深色模式。
- 短板：无术语解释层，小白门槛高。

### 元亨利贞 china95.net
- 工具最全（六爻、八字、奇门、紫微、大六壬、玄空、梅花、金口诀、小成图）。八字表单：姓名、出生地（可不填）、性别、阳历年月日时分（1882–2031）、**「按普通方式排盘 / 按真太阳时排盘」**、**「简排 / 全排」**。不支持农历直接输入、无未知时辰。广告：顶部自营批八字横幅 + AdSense + 右下浮动条；结果新开窗口。视觉 2000 年代门户。来源 https://www.china95.net/paipan/bazi/

### 周公解梦站（zgjmorg.com、zgjm.net）
- 「每个梦境一页」的 SEO 关键词矩阵；详情页右栏「大师测算」导流 + 在线抽签；首页声明「仅供娱乐参考」。无结构化吉凶、无分享。来源 https://www.zgjmorg.com/dongwu/she.html

### 问真八字 / 诸葛八字排盘
- 面向学习者：**术语弹窗给古籍原文 + 白话解释**、「基本排盘 / 专业细盘」双界面、练习题与沙盒、五运六气、十神能量分析、合盘对比。会员 ¥98/季、¥198–258/年、¥698 永久、5 年 ¥898；会员首条权益「去除所有广告」。多名称多主体导致品牌混乱。来源 https://apps.apple.com/cn/app/id1665624645 、https://apps.apple.com/cn/app/id6753684715

### 八字排盘宝 / 周易排盘
- 「每日运程」与万年历、吉日查询绑定；连续订阅 ¥18/月比一次性 ¥25 便宜以引导续费；有数据串号 bug 投诉。来源 https://apps.apple.com/cn/app/id1467145361

### 知命
- 「悬赏提问」UGC 问答 + 真人大师分成；用公农历转换、孕期工具等生活工具做高频入口。iOS 更新停滞。来源 https://apps.apple.com/cn/app/id1104092777

### 三藏算命 sheup.org
- 繁体，30+ 小工具；首页表单只要年月日（不要时辰）；八字页要时分但无未知选项、无真太阳时。页脚「僅供娛樂參考」。来源 https://www.sheup.org/

### 美国神婆（镜像 shenpowang.com）
- **每日运势格式（实测处女座）**：顶部指标「幸运数字 / 贵人星座 / 幸运颜色 / 开运方位 / 今日吉时」→ 一句短评 → 五段文字：整体运势（80–100 字）、爱情（50–70）、事业学业（50–70）、财富（50–70）、健康（60–80）；无星级；今日/明日/本周/本月/年度切换；大师专栏（苏珊米勒等）按时间流排列。来源 https://www.shenpowang.com/yunshi/chunv/
- 星盘表单：昵称、性别、出生时间、**夏令时复选**、出生地点（省市下拉含港澳台与境外）、经纬度、时区下拉。来源 https://www.shenpowang.com/xingpan/

## 横向结论

| 维度 | 观察 |
|---|---|
| 未知时辰 | 仅 ziwei.pub 有方案（辅助定盘问卷）；其余均强制填写或干脆不要时辰 |
| 每日运势 | 中文模板 = 幸运指标行 + 短评 + 分领域段落；量化评分少见，顺历的「凶吉得分」被用户觉得吓人 |
| 价格 | 月卡 ¥18–25、年卡 ¥66–258、永久 ¥168–698；首月低价与连续订阅折扣是转化手段 |
| 广告 | 免费工具站混放自营批命广告 + AdSense + 浮动条；会员第一权益是去广告 |
| 分享 | 几乎没有分享按钮；ziwei.pub 靠 URL 即命盘 |
| 术语解释 | 问真的「古籍 + 白话弹窗」是唯一做得好的；ziwei.pub 缺失 |

## 对天机的直接启示
1. 表单采用 ziwei.pub 的 13 档时辰下拉 + 农历/阳历切换，加上元亨利贞的真太阳时开关与神婆网的夏令时/时区处理，并补上所有竞品都缺的「不知道时辰」一等公民选项。
2. 「辅助定盘」问卷列入二期 backlog（紫微的 12 时辰试排可演化为此）。
3. 每日运势：顶部幸运指标行（幸运色、数字、方位、吉时、贵人星座/生肖）+ 一句短评 + 五维星级 + 分领域段落。星级要配柔和文案，避免「凶吉得分」式恐吓。
4. 术语弹窗必须做：古文原文（可折叠）+ 白话 + 英文释义。
5. 运限时间轴（±日/月/年）是紫微与八字结果页的差异化交互，一期至少做流年/流月切换。
6. 广告只放固定位，不混自营推广，不做浮动条。
