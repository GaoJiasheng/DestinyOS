# 体系规范 · 奇门遁甲（时家奇门 · 转盘 · 拆补法）

> 代码标识 `qimen`。主题：东方。不依赖出生信息；以**起局时刻**（默认当前时刻，用户可指定）排盘，并按问题类别给出用神与吉凶。

## 1. 用户视角的功能

1. 选择问题类别（事业求职、财运交易、感情婚恋、健康、出行、考试竞赛、寻物寻人、综合），可填问题。
2. 起局时刻：默认"现在"（用户所在时区），可改为任意时刻；可选"用我的出生时刻起局"（终身局，需出生时间）。
3. 结果：九宫格盘（地盘天盘干、九星、八门、八神、值符值使、空亡、马星、击刑、入墓、门迫等标记）、局数（阴/阳遁几局）、旬首、符头。
4. 用神分析：按类别指出用神落宫，判断吉凶格局与方位、时机建议。
5. 报告 6 章（§6）。

## 2. 输入与选项

```ts
type QimenInput = {
  at: ZonedDateTime;                       // 起局时刻（用户时区）
  place?: { lng: number; tz: string };     // 可选真太阳时
  category: 'career'|'wealth'|'love'|'health'|'travel'|'exam'|'lost'|'general';
  question?: string;
  options: { school: { layout: 'rotating'; juMethod: 'chaibu'; centerLodge: 'kun2'|'gen8'; useApparentSolarTime: boolean } };
};
```

一期固定：转盘（rotating）、拆补法（chaibu）、中五寄坤二。

## 3. 排盘算法

### 3.1 时间与干支

起局时刻 → （可选真太阳时）→ 年月日时四柱（规则与八字一致；注意日柱 23:00 换日采用与八字相同的 `zi_unified`）。

### 3.2 定阴阳遁与局数（拆补法）

1. 阳遁：冬至 → 夏至前；阴遁：夏至 → 冬至前（按节气精确时刻）。
2. 每个节气 15 天分上、中、下三元，每元 5 天。拆补法：以**节气交接时刻**为界，节气后第 1–5 日为上元、6–10 中元、11–15 下元（按日柱计数，从节气当日算第 1 天），超出的日子"补"入下一节气上元。
3. 局数表（上/中/下元）：
   阳遁：冬至 1/7/4，小寒 2/8/5，大寒 3/9/6，立春 8/5/2，雨水 9/6/3，惊蛰 1/7/4，春分 3/9/6，清明 4/1/7，谷雨 5/2/8，立夏 4/1/7，小满 5/2/8，芒种 6/3/9。
   阴遁：夏至 9/3/6，小暑 8/2/5，大暑 7/1/4，立秋 2/5/8，处暑 1/4/7，白露 9/3/6，秋分 7/1/4，寒露 6/9/3，霜降 5/8/2，立冬 6/9/3，小雪 5/8/2，大雪 4/7/1。

### 3.3 地盘

- 三奇六仪顺序：戊、己、庚、辛、壬、癸、丁、丙、乙。
- 阳遁从局数宫起戊，**顺**九宫数（1 坎、2 坤、3 震、4 巽、5 中、6 乾、7 兑、8 艮、9 离）布六仪三奇；阴遁**逆**布。中五宫的干寄坤二。

### 3.4 旬首、值符、值使

- 时柱所在旬的旬首（甲子戊、甲戌己、甲申庚、甲午辛、甲辰壬、甲寅癸）→ 对应六仪。
- 值符星 = 旬首六仪在地盘所落宫的**九星**（天蓬 1、天芮 2、天冲 3、天辅 4、天禽 5、天心 6、天柱 7、天任 8、天英 9）。
- 值使门 = 该宫的**八门**（休 1、死 2、伤 3、杜 4、中无门、开 6、惊 7、生 8、景 9）。
- 中五宫天禽随天芮（寄坤二）；中五宫门随 death... 具体：中宫无门，值使若落中则寄坤二死门。

### 3.5 天盘

- **值符随时干**：时干在地盘所落宫为天盘值符星落宫（时干为甲时随旬首六仪）；其余八星按转盘顺序（蓬任冲辅英芮柱心，中禽随芮）顺时针依次排列。天盘干 = 原地盘各星所带之干随星转动。
- **值使随时支**：从旬首所在宫起旬首地支（如甲子起子），阳遁顺数、阴遁逆数到时支，所到宫为值使门落宫；其余七门按转盘顺序（休生伤杜景死惊开）顺时针排列。中宫寄坤二。

### 3.6 八神

值符、腾蛇、太阴、六合、白虎（勾陈）、玄武（朱雀）、九地、九天。值符神随值符星落宫，阳遁顺时针、阴遁逆时针依次排。一期使用"白虎、玄武"命名（转盘常用），专业视图标注对应"勾陈、朱雀"。

### 3.7 标记

- **空亡**：时柱旬空两支所在宫。
- **马星**：时支三合局的驿马（申子辰马在寅，寅午戌马在申，巳酉丑马在亥，亥卯未马在巳）所在宫。
- **伏吟 / 反吟**：天盘星与地盘星同宫（伏吟）或对宫（反吟）。
- **门迫 / 门制**：门五行克宫五行为迫；宫克门为制（门受制）。
- **击刑**：庚加寅 / 戊加震……用标准六仪击刑表（戊击刑震三、己坤二、庚艮八、辛离九、壬巽四、癸巽四）。
- **入墓**：乙墓坤、丙墓乾、丁墓艮、戊墓乾（用常用表：乙戌、丙戌……简化为天干入墓宫表：乾六：丙戊；坤二：乙癸；艮八：丁己；巽四：辛壬；庚墓丑）。表以代码常量写明。
- **三奇得使、三奇升殿、青龙返首、飞鸟跌穴、玉女守门、天遁、地遁、人遁、风遁、云遁、龙遁、虎遁、神遁、鬼遁、青龙逃走、白虎猖狂、朱雀投江、腾蛇夭矫、太白入荧、荧入太白、大格、小格、刑格、奇格、伏干格、飞干格、五不遇时** 等格局：实现为规则表，每条给出判定条件（哪个干加哪个干、哪个门落哪个宫）。一期约 40 条。

## 4. 用神与判断

| 类别 | 用神 | 看法要点 |
|---|---|---|
| career | 开门（事业）、日干（求测人）、值符（上司/机构） | 日干与开门落宫生克；开门吉格；值符落宫旺衰 |
| wealth | 生门（财）、戊（资本）、日干 | 生门与日干宫位生克；戊所在宫吉凶；庚（阻碍）是否临日干 |
| love | 乙（女方）、庚（男方）、六合（婚姻）、日干 | 乙庚相加为吉；六合落宫；时干宫 |
| health | 天芮（病星）、日干、乙（医生）、天心（医治） | 天芮落宫旺衰、是否临日干；天心生日干为吉 |
| travel | 景门/开门、马星、日干 | 马星落宫、日干宫是否空亡；门迫 |
| exam | 景门（文书）、丁（文采）、天辅（文曲）、日干 | 景门与日干、丁奇；天辅是否旺 |
| lost | 六合、玄武（盗）、时干（失物）、日干 | 时干落宫方位；玄武宫 |
| general | 日干、时干、值符、值使 | 日干时干关系；值使门落宫吉凶；年命（可选） |

判断输出 `verdict`、`score 0–100`、`favorableDirections: Direction[]`（吉门吉星所在宫方位）、`timing: { favorableHours: Branch[] }`、`findings: string[]`（规则 key）。一期判断规则（权重）：用神落宫吉门 +2、吉星 +1、吉格 +2、凶格 −2、空亡 −1、入墓 −1、门迫 −1、击刑 −1、伏吟 −1、反吟 −0.5、日干宫生用神宫 +1、用神宫生日干宫 +1、克 −1。

## 5. 输出 Chart Schema

```ts
type QimenChart = {
  castAt: { local: string; tz: string; adjusted?: string };
  pillars: { year, month, day, hour: {stem,branch} };
  dun: 'yang'|'yin'; ju: number;                        // 1–9
  solarTerm: { name: string; yuan: 'upper'|'middle'|'lower' };
  xunShou: { stem: 'jia'; branch: Branch; yi: Stem };    // 旬首与六仪
  zhiFu: { star: StarKey; palaceEarth: number; palaceSky: number };
  zhiShi: { gate: GateKey; palaceEarth: number; palaceSky: number };
  palaces: Array<{
    index: 1|2|3|4|5|6|7|8|9;                           // 洛书数
    trigram: Trigram|null; direction: Direction;         // 坎北、坤西南…
    earthStem: Stem; skyStem: Stem;                      // 地盘干、天盘干（中宫寄坤时两者都给）
    star: StarKey; gate: GateKey|null; deity: DeityKey|null;
    hiddenStem?: Stem;                                    // 寄宫干
    flags: Array<'void'|'horse'|'fu_yin'|'fan_yin'|'gate_forced'|'gate_controlled'|'ji_xing'|'ru_mu'>;
    patterns: string[];                                   // 本宫命中的格局 key
  }>;
  useGods: Array<{ key: string; palaceIndex: number; state: string[] }>;
  verdict: Verdict; score: number; favorableDirections: Direction[]; timing: {...}; findings: string[];
};
```

## 6. 报告章节

| # | key | 标题 | 要点 |
|---|---|---|---|
| 0 | `overview` | 局象速读 / The Chart | 阴阳遁几局、值符值使一句话；吉凶判定与分数；最佳方位 |
| 1 | `use_gods` | 用神分析 / Key Indicators | 按类别逐个用神：落宫、门星神、生克、格局 → 通俗结论 |
| 2 | `patterns` | 格局 / Configurations | 命中格局逐条解释（吉格先，凶格后），每条附"对你的问题意味着" |
| 3 | `directions_timing` | 方位与时机 / Direction & Timing | 吉方（含图示八方）、避忌方、吉时段、近期合适的日子（按值使门与用神地支推） |
| 4 | `advice` | 行动建议 / Advice | 3 条 |
| 5 | `pro_view` | 专业视图 / Full Chart | 完整九宫表、拆补推导、旬首值符推导过程 |

## 7. 可视化

- **九宫盘**：3×3 格，上南下北（传统）或可切换上北；每格自上而下：八神（小字）/ 九星 + 天盘干（大字）/ 八门 + 地盘干；中宫显示局数与值符值使。
- **用神高亮**：按类别高亮对应宫位，金色描边 + 短标签"事业：开门在此"。
- **方位罗盘**：盘外圈 8 方位与宫位对应，吉方以绿色扇形标注。
- **起局动效**：九宫格依次点亮（地盘 → 天盘 → 门 → 神），每层 0.3s。
