# 辅助定盘 · B-03

## 范围与入口

- `/[locale]/rectify`：出生信息 → 大致时段与七题问卷 → 十二候选排序 → 前三候选试排。
- 出生表单「我不知道出生时间」与紫微 `E_REQUIRES_BIRTH_TIME` 阻断页提供入口。
- 直接访问且没有档案时复用出生表单；有档案时带入生日、出生地、性别。
- 支持匿名设备档案和登录账户档案。问卷与候选在浏览器计算，不传给服务器。

## 问卷与评分 v1

七题依次为：决策方式、工作/学习投入、群体角色、学习经历、近期变化、长期责任、冲突处理。
每题三个选择加「不确定 / 都不太像」，对应 shared 的 `RECTIFICATION_AFFINITIES`：

- 领导、执行：紫微/武曲/七杀；官杀。
- 研究、观察：天机/巨门/太阴；印星。
- 创意、表达：贪狼/破军/天同；食伤。
- 资源、稳定：天府/武曲/天相；财星、正官。
- 支持、协调：太阳/天梁/天同；正印、食神。

每题命宫任一主星匹配 +2，时柱天干十神匹配 +2；同题多颗匹配不重复加分。
空命宫借对宫主星。问卷最多 28 分；不确定计 0 分。
时段先验匹配 +3，不匹配不扣分、不排除；不确定无先验。
清晨=寅卯、上午=辰巳、中午=巳午、下午=未申、傍晚=酉戌、夜间=戌亥、深夜=子丑。
总分降序排列，同分按子至亥排序；相似度为总分 / 31，展示时取整为百分比。
相似度不是出生时辰概率，全部不确定不会生成正置信度。

## 排盘与知识库

`rectifyBirth(birth, answers, now, locale)` 批量复用 `normalizeBirth`、`computeZiwei`、`computeBazi`。
十二个民用时辰代表点是生日当地 00:00、02:00…22:00；真太阳时、闰月及早晚子时沿用引擎默认流派。
子时代表点不涵盖前后日所有晚子时可能；夏令时和时辰内边界需要出生记录进一步核对。
候选民用时辰与校正后的时柱可能不同，结果页显示实际时柱。
`packages/content/rectification/hours.yaml` 提供十二条 zh/en 一句话观察提示；构建期编入 next-intl 文案。

## 档案、报告与隐私

选中候选后保存 `timeSource='rectified'`、`rectificationConfidence`（0–1），然后试排紫微或八字。
来源与相似度放在 BirthInput 加密载荷；不新增明文数据库字段。匿名档案与跨页草稿沿用 AES-GCM。
登录档案沿用版本化存储，报告关联当前档案版本；已生成报告维持历史快照。
报告显示来源、相似度和未确认提示，页面总置信度以相似度为上限；可修改出生信息或重答问卷。
手动修改出生事实会清除试排来源；只修改显示名保留来源。
题目答案不持久化、不进日志或 URL；页面 noindex，复用年龄限制与报告限流。

## DESIGN-GAP

权重与相似度是未经过经验校准的透明启发式；时段采用软先验。
民用时辰中点、早子代表点、真太阳时跨时辰和 DST 不确定性明确展示。
空宫借对宫；十二条时辰提示只用于观察，不作为出生时间证据。
新增字段放在现有加密载荷；匿名加密草稿用于跨路由；重试沿用幂等键。
