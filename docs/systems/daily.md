# 体系规范 · 每日运势（Daily Fortune）

> 代码标识 `daily`。聚合八字流日、西方行运、塔罗每日一牌、吠陀 Panchang。需要出生档案（匿名用户用本地档案）。

## 1. 页面内容结构（`/today`）

竞品综合结论（见 appendix/research-competitors-part2/3/4）：中文用户熟悉「幸运指标 + 短评 + 分领域段落」，西方用户熟悉「正文 + 评级 + 日切换」，App 端最佳为 Co-Star「一句箴言 + Do/Don't + 领域三态」。天机采用以下顺序：

1. **日期头**：公历日期（用户时区）、农历日期、干支（年月日）、节气（若当日或 3 天内有）、月相图标；日切换「昨天 · 今天 · 明天」（明天可看，后天起为会员功能 P1）。
2. **今日一句**（Day at a glance）：≤ 40 字 / 25 词的箴言式总评，由综合评分区间 + 主导主题 KU 生成。
3. **五维星级**：事业、财运、感情、健康、人际，各 1–5 星 + 6–12 字短语（如「宜推进，忌争辩」）。总评以颜色环呈现而非数字，避免「凶吉得分」式恐吓。
4. **幸运指标行**（横向卡片）：幸运色（色块 + 名称）、幸运数字（1–2 个）、吉利方位、今日吉时（2 个时段）、贵人生肖（与流日地支三合六合）。
5. **宜 / 忌**：各 2–3 条，来自黄历宜忌（库提供）**筛选后**的通俗条目（剔除「安葬」「破土」等不适合现代日常的词，白名单见 §6）。
6. **分领域段落**：事业与学业、财运、感情与人际、健康与情绪，各 60–100 字 / 40–70 词。每段由八字流日 KU + 行运 KU 组合。
7. **今日星象**：月亮星座与月相一句话；与本命的 1–2 条主要行运相位（有则显示）；水逆等集体现象提示。
8. **今日一牌**：卡片翻转动效，牌名 + 正逆 + 一句话；点击进入塔罗体系看完整牌义。
9. **今日 Panchang**（可折叠，默认折叠；用户在吠陀体系使用过则默认展开）：Tithi、Nakshatra、Yoga、Karana、Vara 一行 + 一句话。
10. **Do / Don't**：各 3 条短词（≤ 6 字 / 3 词），从 KU 的 `do`/`dont` 字段按权重抽取并用 seed 打散，让每天有新鲜感。可一键生成分享卡。
11. **本周 / 本月** tab（P1）：同一框架按周/月聚合（流月干支、月亮新满月、主要行运）。
12. 反馈：「今天准不准？」👍👎。
13. 广告位 1 个（第 6 与第 7 节之间，仅免费用户）。

## 2. 输入

```ts
type DailyInput = {
  birth: NormalizedBirth;              // 可 timeUnknown
  baziChart: BaziChart;                // 复用已算好的本命（缓存）
  astroChart: AstroChart | null;       // 本命占星（可能 noonChart）
  vedicChart: VedicChart | null;
  date: { local: 'YYYY-MM-DD'; tz: string };   // 用户当前时区的目标日
  seed: string;                        // sha256(userId|date)
};
```

## 3. 计算规则

### 3.1 八字流日

1. 目标日 12:00（用户时区）→ 流日干支 `(dayStem, dayBranch)`，流月、流年干支（按节气）。
2. `dayMasterRelation` = 流日天干对日主的十神。
3. `branchRelation` = 流日地支与原局日支（优先）/ 年支 / 月支 / 时支的关系：六合 `combine`、三合 `tri_combine`、六冲 `clash`、三刑 `punish`、六害 `harm`、六破 `break`、无 `none`。记录与哪一柱。
4. `todayElement` = 流日天干五行；`favorableHit` = todayElement ∈ `useGod.favorable`；`unfavorableHit` 同理。
5. 流日与当前大运、流年干支的关系（冲合）作为次级因素。
6. 幸运色：按 `useGod.favorable[0]` 五行给颜色族（木：青绿/翠绿/薄荷；火：朱红/橙/玫红；土：黄/棕/米；金：白/银/金；水：黑/藏青/蓝），再用 seed 在族内选 1 个具体色名 + HEX。
7. 幸运数字：五行数（河图：水 1/6，火 2/7，木 3/8，金 4/9，土 5/10）取喜用五行的两个数。
8. 吉利方位：喜用五行方位（木东、火南、土中/西南、金西、水北）。
9. 吉时：当日 12 时辰中，时干对日主为喜用十神且时支与日支不冲者，取前 2 个；没有则取不冲者。
10. 贵人生肖：与流日地支三合、六合的生肖。
11. 宜忌：取库的当日宜忌，按白名单过滤并映射为现代用语（§6）。

### 3.2 西方行运

1. 目标日 12:00 UT 行星位置（日月水金火木土，外行星用当日即可）。
2. 月亮星座与度数；月相（新月 / 眉月 / 上弦 / 盈凸 / 满月 / 亏凸 / 下弦 / 残月）；月亮当日是否换座。
3. 行运相位：行运日、月、水、金、火对本命日、月、水、金、火、ASC、MC（无时间则无 ASC/MC）的合、冲、四分、三分、六分，容许度 月 3°、其他 1.5°；行运木、土对本命日月 ASC，容许度 1°。按紧密度排序，取前 3。
4. 集体现象：水星逆行（速度 < 0）、金星逆行、火星逆行；满月/新月当日。

### 3.3 塔罗

`drawDaily(seed)` → 单张，允许逆位。

### 3.4 吠陀 Panchang

按 astrology.md §4.8，以用户**当前位置**（若授权；否则用出生地/时区默认经纬）计算日出时间与五要素。

## 4. 输出 Schema

见 04 §7 的 `DailyChart`，加：`findings: string[]`、`doDont: { do: string[]; dont: string[] }`、`oneLiner: KUKey`。

## 5. 解读组文（daily 的 KU）

- `daily.oneliner.{band}.{theme}`：band ∈ {great, good, mixed, careful}（按总评），theme = 主导 finding 的主题 → 约 4 × 10 = 40 条。
- `daily.career.{finding}`、`daily.wealth.*`、`daily.love.*`、`daily.health.*`、`daily.social.*`：每个 finding 对应 1–2 条 40–70 字段落 → 约 30 findings × 5 领域（并非全部组合都写，按相关性）≈ 100 条。
- `daily.astro.moon_sign.{sign}`、`daily.astro.moon_phase.{phase}`、`daily.astro.transit.{key}` ≈ 12 + 8 + 30 = 50 条。
- `daily.do_dont`：每条 KU 自带 `do[]`/`dont[]` 短词，不单独写。
- 共约 **200 条**。

每段组文规则：先流日八字段（主），再行运段（辅），用过渡词连接；若两者冲突（八字说宜进取、行运说宜收敛），按权重取主，并加入「不过……」句式的让步。

## 7. 缓存与时区

- `cacheKey = daily:{userId}:{profileVersion}:{localDate}:{locale}:{knowledgeVersion}:{engineVersion}`，TTL 至用户时区次日 02:00。
- 用户时区来自浏览器 `Intl.DateTimeFormat().resolvedOptions().timeZone`，写入 cookie `tz`；服务端缺省用出生地时区。
- 用户切换日期（昨天/明天）用同一规则算，不同 key。
