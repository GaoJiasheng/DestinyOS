# Native widget sources

`widget/` is the WidgetKit extension generated by the `@bacons/apple-targets`
Expo plugin. Host ID: `pub.gavin.tianji`; extension ID: `pub.gavin.tianji.widget`;
shared App Group: `group.pub.gavin.tianji`; Team ID: `D33974QQTD`.

`android/widget.tsx` provides the 2×2, 4×2 and 4×4 RemoteViews through
`react-native-android-widget`. `modules/widget-storage` supplies a small Expo
module for the presentation-only SharedPreferences snapshot. It is autolinked
without editing generated projects. The entry point registers headless tasks
before Expo Router. Android add/resize/periodic updates never read birth records.

All dimensions render precomputed dates, scores, translated copy, colors, numbers,
card thumbnails and good hours. There are no birth fields, profile/account IDs,
tokens or report evidence in either platform's widget storage. Identity changes
clear the former snapshot. Expired predictions show a translated refresh prompt.
An eight-entry civil-day timeline covers today and the following seven midnights,
including DST. The notification planner separately selects seven future daily
reminder times. Special reminders are independently configurable.

After catalog/card updates, regenerate WidgetKit resources from the existing
shared Web assets:

```sh
pnpm i18n:traditional
pnpm exec tsx apps/mobile/scripts/widget-assets.mts
pnpm --filter @tianji/mobile exec expo prebuild --platform ios
pnpm --filter @tianji/mobile prebuild:android
```

Native projects remain ignored. Do not commit signing material. Device builds
need the widget App ID to join the documented App Group. EAS creates this App ID
on the first signed build; simulator builds use local ad-hoc signing (`CODE_SIGN_IDENTITY=-`,
`CODE_SIGNING_ALLOWED=YES`) so Xcode emits simulated App Group entitlements.
Unsigned compilation alone does not enable shared simulator containers.

BackgroundTask is registered at module scope and requests a 60-minute minimum
interval. iOS/Android choose execution time; exact midnight execution is not
promised. WidgetKit's precomputed midnight timeline and Android's 30-minute
widget provider refresh keep dated content current between JS background runs.
On iOS Simulator the diagnostic runs the identical task function directly;
BGTaskScheduler dispatch, locked-device SQLCipher access, reboot and battery
restrictions require physical-device acceptance.

Use a dedicated empty simulator for `/dev/engagement`. It writes only a synthetic
fixture and tests actual OS local notification delivery and both deep links.
Run `bash apps/mobile/scripts/m11-simulator.sh <UDID>` with Metro on port 8081.
Run the widget gallery script next, then use the `M11-lock-widgets` flow on the fresh
wallpaper. Its coordinates are measured on iPhone 17 Pro / iOS 26.4. The two lock
widgets share the same display-only snapshot. `M11-locales` captures the Chinese
and Traditional Chinese settings after the English notification checks.
Evidence goes to `test-results/M11`. Android native build/device checks remain
pending until Owner installs Java; prebuild, autolinking, TypeScript and Jest
checks can run without Java.
