任务：报告导出重做为「一张长图 + 紧凑 PDF」（Owner 反馈：现在 A4 图片导出生成了 15 页、要逐页下载，不可接受；图片应当 all-in-one 一张长图，PDF 也要重新排版压缩）。
阅读：docs/progress/ 下导出相关记录、apps/web 现有 print 布局与导出路由、docs/03-visual-design.md。
要做：
1. 图片导出改为**单张长图**：宽 1242px（移动端 3x）或 1600px 两档可选，高度随内容；布局为紧凑的单栏海报式排版（封面区 → 命盘图 → 各章节连续排列 → 行动清单 → 免责与二维码），字号与间距比网页紧 20–30%，章节之间用细金线分隔而不是分页；用 Browser Rendering 截取 fullPage 一次生成；输出 JPEG 质量 82（或 WebP 质量 80），目标体积 ≤ 3MB；超长（> 16000px）时自动把宽度档位上调或再压缩，但不分页。保留「封面图」单页分享功能。
2. PDF 重新排版压缩：A4，封面与命盘图合并到第 1 页；章节连续流排，不强制每章换页；正文双栏（中文 9.5pt 行高 1.55，英文 9pt），标题与结论句仍突出；原文引用改为脚注样式；图片内嵌为 JPEG 质量 80；字体子集化只嵌入用到的字形；目标：七体系本命报告 ≤ 6 页、占卜类 ≤ 3 页，文件 ≤ 2MB；文字仍可选中可搜索。
3. 导出面板 UI 重做（移动端为底部抽屉、桌面为弹层）：三个主按钮「下载长图」「下载 PDF」「分享封面图」+ 主题切换（暗色星空 / 浅色纸张）；生成中显示进度与预计时间；完成后直接触发下载或系统分享（Web Share API），不再出现逐页下载列表；生成失败有重试。
4. 性能：生成结果按 readingId+版本+语言+主题+格式缓存到 R2 24 小时；同一报告重复请求命中缓存直接返回；Browser Rendering 单次超时 60s，超时返回明确错误。
5. 验收：Fixture A 七体系 zh/en 各生成长图与 PDF，存 test-results/export/，核对：长图无裁切、无空白段、二维码可扫；PDF 页数与体积达标，文字可搜索；自动化测试检查页数、体积、尺寸上限；更新 test:polish 截图基线与 docs/03、docs/progress/EXPORT-ONEPAGE.md。提交，不部署。
